# Topics in Java

A structured repository containing practical examples, code snippets, and explanations of fundamental to advanced core Java concepts.

## 📋 Overview
This repository serves as a learning guide and reference for Java developers. It covers essential core concepts, built-in standard methods, standard library classes, and object-oriented programming fundamentals.

## 📚 Topics Covered
- **`charAt` (`CHARAT.java`)**: Demonstrates the `charAt()` method of the `String` class to fetch characters at specific indices.
- **`length` (`length.java`)**: Explores string length determination and array length properties in Java.
- **`java.lang.Object` (`java.lang.object.java`)**: Covers the root class of the Java class hierarchy, including foundational methods like `toString()`, `equals()`, `hashCode()`, and `getClass()`.
- Additional core topics including OOP principles, collections framework, and standard utility functions.
